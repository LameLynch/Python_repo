# 🎮 Stone Paper Scissors

A simple command-line Stone Paper Scissors game built with Python. Play against the computer over multiple rounds while keeping track of the score.

---

## Features

- 🎲 Random computer choice
- 👤 Player name input
- 🔁 Custom number of rounds
- 🏆 Score tracking
- ✅ Input validation
- 📢 Announces the winner after each round
- 🎉 Displays the final winner

---

## Technologies Used

- Python 3
- Built-in `random` module

---

## How to Run

1. Make sure Python 3 is installed.
2. Clone this repository:

```bash
git clone https://github.com/your-username/Stone-Paper-Scissors.git
```

3. Open the project folder:

```bash
cd Stone-Paper-Scissors
```

4. Run the program:

```bash
python main.py
```
